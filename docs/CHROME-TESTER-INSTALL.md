# ClarityOne Chrome Test Install (No Chrome Web Store)

Use these steps to install the test build directly in Chrome for free.

## 1) Unzip
- Unzip the package you received.
- Keep the `clarityone-unpacked` folder somewhere permanent (Desktop/Documents is okay).

## 2) Enable Developer Mode
1. Open Chrome and go to `chrome://extensions`.
2. Turn on the `Developer mode` toggle (top-right).

## 3) Load the extension
1. Click `Load unpacked`.
2. Select the `clarityone-unpacked` folder.
3. Confirm ClarityOne appears in your extensions list.

## 4) Pin and verify
1. Click the puzzle icon in Chrome toolbar.
2. Pin `ClarityOne`.
3. Open any website and verify the popup opens and settings apply.

## Updating to a newer test build
- Remove the old extension from `chrome://extensions`.
- Delete old `clarityone-unpacked` folder.
- Repeat the install steps with the new tester zip.

## Notes
- This method is intended for testers and internal QA.
- Browser updates may disable unpacked extensions until re-enabled.
